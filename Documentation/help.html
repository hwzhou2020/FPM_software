FPM Software — Professional Help Guide

Everything you need to install, run, and use the Professional Edition.

Quick Start

  1. Clone the repository 
    git clone https://github.com/hwzhou2020/FPM_software.git
cd FPM_software
  2. Launch the Professional UI 
    python launch_fpm_professional.py

    If the splash screen produces a QPaintDevice warning, run python launch_fpm_no_splash.py.

Loading Data

  • Click Load (or press Ctrl+O).
  • The dialog opens in the bundled data/ folder by default.
  • Select a .mat dataset; required fields (e.g., imlow, NA_list) are validated automatically.

Tip: recent files are available via Specs → Load Specs.

Running a Reconstruction

  1. Load data.
  2. Select an algorithm in Specs → Algorithm specs.
  3. Adjust parameters if prompted.
  4. Click Run or press Ctrl+R.
  5. Track progress in the status bar and message window.
  6. The amplitude image displays automatically when finished.

Saving & Reloading Results

  • After a successful run, use Save or File → Save Results.
  • Outputs are stored in the project Results/ folder (auto-created) with amplitude, phase, pupil arrays, algorithm parameters, ROI info, and source data name.
  • To reload later, choose File → Load Results and open the saved .mat or .npy archive.

Keyboard Shortcuts

  • Ctrl+O — Load data
  • Ctrl+R — Run selected algorithm
  • Ctrl+Shift+S — Set save directory
  • Ctrl+Q — Exit application
  • F1 — Open this documentation

Troubleshooting

  • No output after loading: verify imlow and NA_list are present in the .mat file.
  • Memory errors: reduce ROI size or algorithm upsampling.
  • Missing PyTorch on macOS: rerun python install_fpm.py (Apple Silicon wheels are handled automatically).
  • GUI issues: launch with python launch_fpm_no_splash.py.
